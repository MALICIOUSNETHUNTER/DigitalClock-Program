# Digital Clock in C

A simple digital clock program written in C that displays the current system time in real-time.

## Features
- Displays current time in HH:MM:SS format
- Updates every second
- Colored console output (Green)
- Shows local time (IST)

## Technologies Used
- C Programming Language
- Windows API
- time.h
- windows.h

## How to Compile (Windows)

Make sure GCC is installed.

```bash
gcc Clock.c -o Clock
```



## How to Run
```bash
Clock
```

## Notes

- Windows-only program (uses windows.h and Sleep())
